## Overview

TaskFlow is a proposed web-based project and task management platform designed to help small teams and organizations manage projects, assign tasks, track progress, and collaborate efficiently.

The purpose of this project is to establish a comprehensive Software Requirements Document (SRD) defining the project's objectives, scope, functional requirements, non-functional requirements, business rules, use cases, constraints, and development planning considerations.

## Project Objectives

- Centralize project and task management.
- Enable project managers to assign tasks to individual team members.
- Track task progress and deadlines.
- Support team collaboration through task comments.
- Provide dashboards and project progress summaries.
- Send in-app and email notifications.
- Establish clear functional and non-functional system requirements.

## User Roles

1. **Workspace Owner:** Manages the workspace, invitations, and member permissions.
2. **Project Manager:** Creates projects, assigns tasks, and reviews completed work.
3. **Team Member:** Works on assigned tasks, updates progress, and collaborates with the team.

## Key Features

- User registration and authentication
- Workspace and team management
- Project creation and management
- Task creation and single-member assignment
- Task status tracking and manager approval
- Task comments and collaboration
- Notifications and deadline reminders
- Dashboard, search, and filtering
